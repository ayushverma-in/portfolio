# Ayush Verma — Portfolio

A modern and interactive personal portfolio website showcasing my projects, skills, and certifications.

🌐 **Live Demo:** [View Portfolio](https://ayushverma-site.netlify.app)
---

## 🚀 Features
- Animated splash screen
- Interactive Three.js background
- Custom cursor experience
- Certificate viewer (5 embedded PDFs)
- Project showcase with modals
- Dark / Light theme toggle
- Background music player
- Fully responsive design

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Three.js

---

## 📂 Project Structure
| File | Description |
|------|-------------|
| `index.html` | Main structure of the website |
| `style.css` | Styling and layout |
| `script.js` | Interactivity and functionality |
| `threejs-bg.js` | Three.js background logic |
| `assets/` | Media files (music, certificates, etc.) |
